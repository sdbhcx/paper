# 2D 可供性知识从哪来、怎么落到 3D 点云

> 核心命题：**2D 和 3D 之间没有语义 gap，只有表征 gap 与视角 gap。**
> 同一物体、同一功能部件在 2D 图像和 3D 点云里是同一个物理实体，所以 2D 学到的"把手是什么样"对 3D 天然成立。
> 真正的困难是：(a) 2D 是规则稠密像素、3D 是稀疏无序点，两者没有内建对应；(b) 2D 是单视角、有遮挡，3D 是完整形状。
> 因此**所有 2D→3D 迁移方法的差异，最终都归结为"用什么建立 2D 像素 ↔ 3D 点的对应"**，损失函数只是次级选择。

---

## 一、2D 侧的 affordance 知识有三种来源（关键区分）

领域文献常把三者混称为"2D 语义知识"，但它们的知识类型完全不同，直接决定迁移后能支撑什么。

### A 类 · 自监督表征涌现（不是学 affordance，是学部件级关系结构）

- **载体**：DINOv2 / DINOv3、SAM、CLIP、MAE 系列。
- **它有没有被 affordance 监督过**：没有。训练目标是自蒸馏 / 掩码重建 / 图文对比。
- **为什么仍含可供性信息**：affordance 在 Gibson 意义上是关系属性，但视觉上高度可感知；互联网图像中功能部件与"手"强共现。自蒸馏要求同一物体不同增强视角下**部件表征一致、部件之间可区分**，这恰好逼着模型把手柄、座面、刀柄这类"功能一致区域"编码成独立簇。
- **它真正给出的是**：密集特征 + **部件之间的关系结构**（谁和谁属于同一功能单元）。
- **它给不出的是**：该接触哪里、往哪个方向施力、接触如何随时间演化。
- **证据**：Unlocking/CMAT 的 Fig.1 可视化显示 DINOv3 提升特征已把把手、座面聚成清晰簇；且消融中 DINOv3 换 DINOv2 后 PIADv2 Seen aIoU 从 44.88 掉到 43.26 —— 教师越强迁移越多，说明这部分知识确实是"涌现"的、随底座强度变化。

### B 类 · 交互证据监督（字面意义上在学 affordance）

- **载体**：HOI 图像 / 视频 + 接触标注；动作识别数据集（UCF101、HMDB）转 affordance 监督。
- **监督信号来源**：**人怎么用** —— 手部接触区、动作轨迹、接触的时序演化、施力与方向。
- **代表**：VAGNet / PVAD、VideoAfford / VIDA、EgoAfford、HAMMER、IAGNet 的 2D 侧。
- **方法论意义**：VAGNet 明确把 affordance **从几何属性重定义为动作驱动的关系**，指出静态线索在形状相似但功能不同（刀刃 vs 刀柄、瓶口 vs 瓶身）时必然失效，因为单帧承载不了接触、施力与滑动。
- **它给出的是**：接触热图 + 交互轨迹 + 方向信息。
- **代价**：标注/配对成本最高，且视频-点云配对是松散一对多（VIDA 训练时一个点云对应多条视频，只在评测时严格一对一）。

### C 类 · 语言世界知识推理（绕开标注，靠常识 + 视觉定位）

- **载体**：Qwen、GPT-4o、MolMo、LISA 等 VLM/MLLM。
- **机制**：语言预训练里的常识（"开抽屉要拉把手"）+ 链式推理把任务词解析为功能部件词 + 视觉定位出候选点/掩码。
- **代表**：Fun3DU（LLM CoT 抽功能物体 → VLM+SAM 多视角分割 → 投票聚合）、TASA（Qwen 抽功能概念 → MolMo 出点 + SAM 出掩码 + 双重检查 → Point Transformer 几何细化）。
- **它给出的是**：稀疏的分割提案 + 可解释的推理链；开放词汇、零训练可行。
- **它给不出的是**：稠密且边界精确的几何；误检/漏检需靠第二轮语义自校验（TASA 双重检查）或几何后端修正。

> **一句话判别**：A 告诉你"这是把手"，B 告诉你"手在这里、往这个方向拉"，C 告诉你"要开门就得找把手，大概在这一带"。

## 二、迁移的统一分析框架：四要素

任何一篇 2D→3D 迁移工作，都可以拆成四个问题：

| 要素 | 要回答的问题 | 常见取值 |
|---|---|---|
| **What** | 迁移什么 | 密集特征 / 掩码 / 亲和矩阵 / 软标签 / 提案点 / 推理链 |
| **Where** | 注入到 3D 的哪 | 预训练骨干 / 双分支教师 / 高斯基元潜码 / 伪标签 / 直接输出 |
| **Correspondence** | **怎么建立 2D 像素 ↔ 3D 点对应** | 多视角反投影+插值 / 3DGS 渲染 / 深度投影+投票 / 跨注意力软对齐 |
| **Loss** | 用什么目标压进去 | MSE 一致 / 亲和矩阵对齐 / 对比损失 / CE 伪标签 / 多视角一致损失 / 无（仅前向注入） |

**判断优先级：Correspondence > What > Where > Loss。** 对应关系错了，损失设计再精巧也是在优化一个错的目标。

## 三、四类对应通路（机制主体）

### ① 多视角反投影 + 插值：把 2D 特征"抬"到点上

- **做法**：对同一物体渲染/采集多视角图 → 冻结 VFM 提密集特征 → 用已知相机参数反投影 + 最近邻插值 → 逐点 2D 描述符 $F^{2D}$。
- **代表**：Unlocking / CMAT（Objaverse + Behavior-1K 一万+模型，12 视角，DINOv3 ViT-L 最后一层特征）。
- **迁移的关键设计**：**不逐点对齐特征，而是对齐 patch 间的亲和矩阵**。
  - 点云分 64 个 patch，patch 内平均池化得 $\bar f^{2D}_j$、$\bar f^{3D}_j$；
  - $A_{jk} = \bar f_j \cdot \bar f_k / (\|\bar f_j\|\|\bar f_k\|)$，$L_{aff} = \sum_{jk}(A^{3D}_{jk} - A^{2D}_{jk})^2$；
  - 辅助 $L_{rec}$（PointMAE 式掩码重建，mask ratio 60%）+ $L_{div}$（KoLeo 正则防坍塌）；
  - 权重 $\lambda_{rec}=1.0, \lambda_{aff}=0.1, \lambda_{div}=0.2$，150 epoch，bs 128，AdamW lr 1e-4。
- **为什么是亲和而不是逐点**：逐点 MSE 只要求"这个点的特征像 DINO 的这个点"，亲和矩阵要求"3D 里各部分的**关系结构**和 2D 一致"，这才是功能语义的载体。
- **消融（PIADv2 Seen aIoU）**：$L_{rec}$ only 39.27 → +$L_{aff}$ 44.13 → +$L_{div}$ 44.88；换 PointNet++ 骨干 37.91，PointMAE 原始权重 38.16。
- **地位**：2D 只出现在预训练，推理纯 3D（+ 轻量 LAS 分割头，六层 co-attention）。300M / 4–8 GB 胜过 4B+ / 16–30 GB 的 GREAT（38.03）。

### ② 3DGS 渲染桥：让每个像素可追溯到某个点

- **做法**：把点坐标直接作为高斯中心 $\mu = P$，人工设定并**冻结**协方差 $\Sigma$ 与不透明度 $o$，多视角渲染深度着色图 → 送冻结 DINOv2。
- **代表**：GEAL（CVPR 2025）。
- **为什么需要这一步**：直接把点云投影到图像平面得到的仍是稀疏散点，缺连续表面、遮挡与深度线索，预训练 2D 骨干提取不到有效语义。3DGS 把稀疏点变成 DINOv2 能吃的"逼真图"，**同时保持每个像素到高斯的追溯关系**。
- **迁移机制**：
  - GAFM（粒度自适应融合）：拼接多层视觉特征，带噪门控 $W=\mathrm{Softmax}(f^{2D}_{con}W_g + \sigma\epsilon)$ 学层级权重，文本条件交叉注意力注入任务语义；
  - CAM（一致性对齐）：把 3D 点特征作为高斯属性渲染到 2D，在共享嵌入空间与 2D 分支特征做 MSE；
  - 两阶段：先训 2D 分支，冻结后训 3D 分支；**推理只跑 3D 分支**。
- **2D 文本侧细节**：二维分支的文本会加视角前缀（"给定某物体前视角的深度图"），使文本特征携带渲染视角信息。

### ③ 深度投影 + 跨视角投票：用掩码提案，不做特征对齐

- **做法**：2D 出掩码或提示点 → 用相机内外参投影/反投影到点云 → 跨视角多数投票聚合 → 得到 3D 粗掩码 → 局部几何网络细化。
- **代表**：Fun3DU（零训练，投票聚合）、TASA（AAAI 2026，MolMo+SAM 出掩码 → 粗 3D 掩码 → Point Transformer 细化）、PointGS（SAM 掩码 → 对比蒸馏进高斯 → ICP+NN 回传点）。
- **TASA 的关键工程归纳偏置（值得抄）**：
  - 视角先筛：整句 CLIP 相似度 + 功能概念加权分数，只保留 top-K（K=10）；
  - 双重检查：反向验证（"与该点交互能否完成任务、是否属于目标功能部件"）+ 失败回退（按抽出的功能概念重查）；
  - 局部细化：只在粗掩码邻域采样 8192 点跑 Point Transformer，相对位置编码进入注意力权重 $w_{ij}=\mathrm{MLP}_w(k_j-q_i+\gamma_{ij})$ 与聚合项；
  - 损失 $L=0.3L_{BCE}+0.3L_{Dice}+0.2L_{Focal}+0.2L_{IoU}$。
- **分工哲学**：**2D 负责语义召回（可能在哪），3D 几何负责空间精度（究竟是哪一片）**。

### ④ 跨注意力软对齐：不建硬对应，让注意力学

- **做法**：点云特征作 Query，2D/视频/HOI 特征作 Key/Value，跨注意力注入后解码 affordance 掩码。不要求任何显式的 2D-3D 对应。
- **代表**：VAGNet（MCAM 在 2D 空间用上下文注意力对齐投影前景与视频帧背景，再跨注意力注入点云；STFM 沿时间融合）、VideoAfford（视频 MLLM + 潜在动作编码器 + 空间感知 Dice）、QueryMe（affordance query 在 3D HOI / text / 3D object 三域顺序检索）、Unlocking 的 LAS（提示词元与几何词元 co-attention）。
- **代价**：推理时**仍需 2D/视频输入**（VAGNet 推理需 TimeSformer 提视频特征，QueryMe 推理仍需 HOI 图）。这与"蒸馏后只跑 3D 分支"的路线是根本对立。

### 补充：蒸馏进中间场（3DGS 潜空间）

- **IAAO**：把 CLIP / SAM / DINOv2 三类 2D 基础模型的输出蒸馏进高斯基元的低维潜空间，用三个小 MLP 解码器还原 2D 特征；SAM 出跨视角掩码聚类标签场，CLIP 出实例/部件级文本特征供语言查询，DINOv2 出像素特征驱动 2D-3D 对应以恢复铰接。
- **3DAffordSplat**：**对照组**——不做 2D→3D，而是点云 ↔ 3DGS 的 3D→3D 结构亲和对齐（CMSA），证明"不依赖 2D 语义、仅靠 3D 内部模态对齐 + 标注"也能立起 3DGS affordance 表征。

## 四、五条硬结论

1. **对应质量决定迁移上限。** GEAL 用 3DGS 建可微对应、Unlocking 用多视角反投影、TASA 用投影+投票、VAGNet 干脆不建硬对应交给注意力 —— 这是四条路线的第一性差异。损失形式（MSE / 亲和 / 对比 / CE）是次级选择。
2. **关系结构比逐点特征值钱。** CMAT 消融：$L_{rec}$ only 39.27 → +$L_{aff}$ 44.13（+4.86），而 +$L_{div}$ 只有 +0.75。对齐"部分-部分关系"而非"点-点数值"是本方向最稳的增益来源。
3. **2D 出语义召回，3D 必须补几何精度。** TASA 的 mAP 23.2 / AP50 26.9 显著高于 Fun3DU 的 7.6 / 16.9，但 AP25 反而更低（28.6 vs 33.3）——因为 Fun3DU 的掩码大而粗糙、在宽松阈值下占优。**"边界变紧"才是真正的能力提升**。
4. **3D 侧的几何信号在小数据下最稳，堆模态可能有害。** TASA 消融：三维细化阶段加颜色或文本**全部退化**，最差组合 mIoU 掉到 2.8。这与"多模态一定更好"的直觉相反，提示在稀疏 affordance 标注下，相对位置几何是最可靠的监督信号。
5. **推理时是否还依赖 2D，是路线的分水岭。**
   - 依赖：VAGNet（需视频）、VideoAfford（需视频 MLLM）、QueryMe（需 HOI 图）；
   - 不依赖：Unlocking（CMAT 预训练后纯 3D）、GEAL（两阶段后纯 3D）、TASA（2D 只出粗先验）。
   - **用户路线的差异点正在这里**：QueryMe 推理需 HOI 图，而蒸馏后的 student 只需物体点云。

## 五、对用户研究路线的直接含义

用户路线：文本 + 3D HOI 点云（2D HOI 图经 VGGT 前馈重建）→ 3D MLLM → contact intent embedding → 与物体点云解码 → affordance/接触预测；担忧是 HOI 几何在 3D MLLM 里被压没、退化成"只换输入没用几何"。

### 【论证修正 2026-09-02】显式接触几何主张必须收缩

> 初稿中"蒸馏目标必须是显式 3D 接触几何"这一表述**过强，已被反驳并修正**。

**被证伪的部分**：不能用"VAGNet/VideoAfford 这么做"来支撑显式几何的必要性——它们**没有**做。VAGNet 的监督是逐点 affordance 掩码（损失仅 Focal + Dice），视频侧由冻结 TimeSformer 提供**隐式**动作特征；VideoAfford 的潜在动作编码器同样是 latent。二者均不做接触点检测、不预测轨迹、不输出方向场。

**为什么这不构成反驳**：两篇是**同输入设定**，推理时交互证据仍在线（VAGNet 推理需 TimeSformer 提视频特征，VideoAfford 需完整视频 MLLM）。交互信息**不需要被记住**——推理时直接从视频里读，所以隐式注入足够。用户路线是**异输入蒸馏**，推理时 HOI 完全不存在，intent embedding 成为**唯一信息通道**，所有交互知识必须预先压进这条 d 维通道。

**结论：分水岭不是"显不显式"，而是"推理时证据在不在"。** VAGNet 式的隐式注入在其自身设定下成立，不能外推到异输入蒸馏。

**修正后的主张（收缩）**：不是"必须输出显式 3D 接触几何"，而是**不能让 intent embedding 成为唯一通道**。可选的几何承载形式（三选一或组合）：
- **(a) 辅助接触几何头**：teacher 侧加一个预测接触区/接触法向的头，其输出作为 `L_ground` 的蒸馏目标；推理时可丢弃。
- **(b) 结构化接触 tokens**：把单个 intent embedding 换成 N 个绑定到共享锚点的 token，容量足以承载稠密接触区，且不需要稠密几何标注。
- **(c) 共享锚点上的关系/亲和矩阵对齐（AMRA）**：只要求对应关系，不要求稠密几何 GT，与 CMAT 的成功范式同构。

**显式几何修正后的定位**：它不是最终交付物，而是**训练期的硬约束**——逼 teacher 真正使用 HOI 几何，给蒸馏一个绕不开语义捷径的目标。

### 单图 VGGT 的能力边界（比"要不要显式几何"更根本）

单张 HOI 图 → VGGT 前馈重建 → **静态** HOI 点云。由此可得与不可得：

| 可得（几何可测，无需标注） | 不可得 |
|---|---|
| 接触区：手点云与物体点云的空间邻近 | 运动方向（往哪拉 / 推 / 转） |
| 接触法向：接触点处物体表面局部法向 | 动作轨迹与时序演化 |
| 手-物相对位姿、抓取构型（若有手模型） | 施力大小与因果 |

→ **静态 HOI 点云本身只能提供"接触位置 + 接触法向"。** 但**方向缺口可被 2D 侧补上**：HOI 照片上的 2D 接触流场本身含方向信息，经可微渲染（把 3D 接触方向投影成流图并与 2D 目标比对）即可反推 3D 接触方向场，无需 3D 方向标注。
→ 因此"单图拿不到方向"应精确表述为"**静态点云拿不到，2D 流场 + 可微渲染可以**"。剩余真缺口是**单视角下 out-of-plane 分量不可观**，需多视角（HOI 视频多帧天然提供多相机）。
→ 若不引入这套 2D 渲染监督，则运动方向只能由 MLLM 的语言先验补足，teacher 知识从纯 B 类**滑向 B∩C 类**，novelty 相应缩水。

**建议**：当前按单图设定走（与 QueryMe 的"单张 HOI 图"设定一致），明确声明能力边界；时序版作为第二阶段扩展。

### 最大的实证风险：teacher 走语义捷径

若只监督最终 affordance mask 或只对齐 intent embedding，MLLM 完全可能学会"看到把手形状就预测抓握"，**根本不使用 HOI 点云**。此时蒸馏出的 student 相比直接用 GT 训练没有增益，整条 HOI 分支是装饰品。

**判别实验（必须最先做，成本极低）**：对 teacher 做输入消融——
1. 完整 HOI 点云（手 + 物体）；
2. 去掉手部点云，只留物体点云；
3. 保留手部点云但随机打乱其空间位姿。

若 2 或 3 相对 1 **掉点不明显**，说明 teacher 没在用交互几何，路线 premise 不成立，应停止投入。**该实验直接检验用户原有的核心担忧（"只换输入、没用几何"）。**

### 为什么必须在推理时移除 HOI（保留 HOI 的三重代价）

> 反问："推理时不移除 HOI 交互证据是否就可行了？" 答：**技术上可行**（信息瓶颈立刻消失，(a)(b)(c) 都不必做），但会摧毁这条路线唯一的立身之本。

**代价一：novelty 归零。** 保留 HOI 后，方法退化为「HOI 证据 + 物体点云 + 文本 → affordance」，与 QueryMe、VAGNet、VideoAfford **完全同一生态位**；且推理链更长更贵（多出 VGGT 前馈重建 + 3D MLLM，而 QueryMe 只需 HOI 图 + 点云 + 文本）。此时必须正面回答"凭什么更贵还更好"，这是极难打赢的仗。

**代价二：整套 machinery 失去存在理由。** 若推理时 HOI 图仍可用，最直接的路线是「2D HOI 图 → 2D affordance → 投影/投票到 3D」（Fun3DU / TASA 路线）。VGGT 重建 + 3D MLLM 的全部 rationale 就是"**把交互知识内化进 3D 表征，使推理时不再需要它**"。保留 HOI 等于抽掉这个 rationale，审稿人必问：既然 HOI 图还在，VGGT 与 MLLM 各贡献了多少？（对应的 ablation 大概率显示贡献有限。）

**代价三：任务定义层面会滑出 affordance 本义。** affordance 是**物体的属性**（这个物体能支持什么动作），不是交互事件的属性。若推理时必须看到"有人正在和它交互"，做的其实是 **HOI parsing / 交互条件下的区域定位**。真实机器人面对的是从未被交互过的新物体，**没有 HOI 照片可给**——这是部署层面的硬约束，不是可选的工程取舍。

**这个批评对 VAGNet / VideoAfford 同样成立**：video-guided affordance 这一子方向的共有软肋就是推理时依赖交互视频。**移除 HOI 反而使本路线在概念上比它们更纯粹**，这是可以写进 related work 的正面论点。

**保留 HOI 唯一正当的用途：上界与分析臂。** 同时报告 with-HOI（上界）与 without-HOI（实际方法）两个数字，其 gap 即"蒸馏损失了多少"，是论文必须报的量。

**判别规则**：若 with-HOI 与 without-HOI 差距极小，说明 HOI 分支本就没贡献，应先回去做 teacher 输入消融（去掉手部点云 / 打乱手部位姿），而不是继续调损失权重。

---

1. **HOI 里真正稀缺的是 B 类知识，不是 A 类（已按上文修正）。** DINO 类语义（"这是把手"）用物体点云本身也能获得一部分；HOI 不可替代的价值在于**接触位置、相对位姿、接触法向**（B 类在单图设定下的可得子集）。因此蒸馏需要**某种几何承载机制**（上文 a/b/c 之一），而不是一个只做分类的 intent embedding。
2. **intent embedding 是瓶颈，不是载体（已按上文修正）。** 若只把 HOI 压成一个向量再解码，接触几何（稠密、带法向、局部相对性）会被不可逆地压缩掉。修正后的解法是三选一：辅助接触几何头 / 结构化接触 tokens / 共享锚点 AMRA —— 它们让"几何"在训练期有独立的可微通路，而不是指望 intent embedding 自己保住几何。
2b. **这条路线可行，但有两条硬边界。** 可行：QueryMe 已证明单张 HOI 图 + 物体点云 + 文本的三域检索能带来 AUC +4.19，inputs 的物理可得性没问题。硬边界一：**推理时 HOI 不存在**，交互知识必须在训练期全部压进 student 权重，这是 VAGNet 从未面对过的设定（它推理时视频在线）。硬边界二：**单图设定拿不到运动方向**（见上文能力边界表）。两者都不否定路线，但都必须在论文里显式声明，不能含混。
3. **TASA 结论支持"3D 侧必须有显式几何通道"。** 冻结 2D VLM + 显式几何通道（投影/投票/局部几何网络）即可保住几何，且加颜色/文本反而退化 —— 外部证据支持设计原则 ③④。
4. **CMAT 的关系对齐与 SRKD 的 AMBRA 是同构的。** 二者都在对齐"关系/亲和矩阵"而非逐点特征；CMAT 的消融（+4.86 aIoU）是该设计在本领域最强的独立证据，可作为引用支撑。把 AMBRA 的类别感知权重换成**接触感知权重**，就等于把 CMAT 的成功范式搬到异输入（HOI→物体）设定。
5. **残留风险**：B 类知识在 teacher 侧本身来自单目重建（VGGT），重建误差会直接污染接触几何的 GT；共享锚点（canonical 帧 + FPS 采 K 点）能缓解但不能消除，需在实验中量化重建误差对 `L_ground` 的敏感度。
