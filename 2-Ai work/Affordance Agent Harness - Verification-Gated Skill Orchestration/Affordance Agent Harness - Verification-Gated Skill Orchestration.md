## 原文摘要翻译

可供性接地要求智能体在开放世界场景中识别应在哪里以及如何交互，而可操作区域往往细小、被遮挡、反光且视觉上含糊。近年系统因此组合多种技能（如检测、分割、交互想象），但大多数仍用固定管线编排它们：固定管线与逐实例难度不匹配、对中间错误缺乏定向恢复、也无法复用重复出现物体的经验。这些失效暴露出一个系统问题：测试时接地必须获取正确的证据、判断证据是否可靠到可以提交，并在无标签、推理成本有界的前提下完成。我们提出 Affordance Agent Harness——一个闭环运行时，它用统一的证据库与成本控制整合异构技能，检索情节记忆为重复类别提供先验，并由路由器自适应地选择与参数化技能；一个可供性专用的验证器随后用自一致性、跨尺度稳定性与证据充分性对提交进行门控，在最终裁判融合累积证据与轨迹给出预测之前触发定向重试。在多个可供性基准与难度受控子集上的实验表明，该方法相对固定管线基线取得更强的精度-成本帕累托前沿，在提升接地质量的同时降低了平均技能调用次数与延迟。

## 创新点

- **把测试时接地重构为「预算约束下的证据获取」**：不再一次前向出预测，而是在技能调用预算内循环「获取证据 → 相对验证 → 定向补证」，这是对可供性智能体（A4-Agent 一类固定脚本）的范式级替换；执行路径由观测到的失效模式决定，而非预定脚本。
- **可供性专用的三诊断量验证器**：跨技能一致性（检测框与分割掩码在同一感兴趣区的重合度）、跨尺度稳定性（缩放/重裁剪后预测的漂移）、证据充分性（带权独立支持计数），三者合成为提交分，并配「全局阈值 + 一致性硬下限」双条件提交规则——无标签测试时只有相对可行动的诊断，不承诺绝对正确性。
- **带溯源的七元组证据记录**：每条中间结果都带类型、载荷、感兴趣区、尺度、生产者编号、成本、步骤索引；生产者编号使跨技能一致性检查与「冲突时该重跑谁」成为可执行操作，这是闭环纠错的最小充分数据结构。
- **两层记忆 + 经验胶囊代谢**：离线常识库（频繁物体的原型先验，带参考掩码）与测试时情节库（仅回写验证器接受的轨迹）分离；容量满时最旧条目压缩为经验胶囊回存，兼顾长期效用与有界存储。
- **分层路由控制 API 成本**：路由按估计「验证分增益/成本」比选择技能，但约 85% 的决策由验证器缺口启发式直接解决，仅近平手或连续两轮同缺口时才升级到 LLM 全量思考——把贵的大脑调用留给少数难例。
- **实证层面**：单框架内替换六种决策大脑均超过固定管线与专用模型基线（ReasonAff 最佳 gIoU 69.68），并以更少令牌、更低延迟、更低成本超过固定全技能链与 A4-Agent。

## 一句话总结

A-Harness 用「证据库 + 两层记忆 + 收益-成本路由 + 三诊断验证门控」把可供性接地从固定管线改成预算化闭环：简单样本一次检测即出（600 例中 500 例单次解决），难例才触发缩放、搜索、交互想象等定向补证，最终在 ReasonAff / UMD / RAGNet 上以约一半的令牌和延迟超过固定管线与 A4-Agent——代价是对闭源大模型接口的重度依赖，且相对最小双技能基线成本不降反升。

## 研究问题

![[images/page_002_fig_fig_1_review.png]]
*图 1：既有可供性智能体（固定脚本 + 晚融合 + 无门控）与 A-Harness（路由 + 记忆 + 验证器 + 预算的闭环运行时）对比。*

- **既有智能体范式的三种失效模式**（作者自陈，图 1）：
  ① **灵活性缺失**：技能按预定顺序执行，简单样本被过度处理，小目标、遮挡、分布外类别却拿不到针对性补证；
  ② **无门控**：检测框、分割掩码、交互点在工具与尺度间冲突时只做晚融合，不定位失效源、不重调责任技能，静默错误向后传播；
  ③ **无持久经验**：重复物体与类别从零重解，成功工具链与物体级先验不被摊销。
- **核心重构**：把任务当作**预算化证据获取**而非单次预测。测试时没有真值，「验证」只能提供**相对且可行动**的诊断——判断当前证据是否可信到可以提交，若否，指出缺什么证据。三条信号族：
  ① 跨工具一致性（同一区域内检测、分割等线索的吻合度）；
  ② 跨尺度稳定性（缩放、重裁剪后可操作区域是否保持）；
  ③ 证据充分性（证据库中可溯源的独立支持是否足够）。
- **与相关路线的边界**：证据中心融合（Dempster-Shafer、折扣可靠性）提供理论基础，但本文把它们落成「触发哪个技能重跑」的可执行策略；think-with-pixels 与工具使用框架提供组合技能的可行性，但缺少提交门控与经验摊销。

## 数据与任务定义

- **任务**：给定观测 $x$（单图或多视角）与可选指令 $q$，预测逐像素的可供性概率图（二值或软掩码，取值介于 0 与 1，与原图同分辨率）；框架可扩展到关键点或接触区域。
- **技能池**：检测、分割、放大、网络搜索、交互想象（Dreamer）五类，每次调用计一次成本；主预算按调用次数计，延迟与货币成本作次要指标。
- **基准**：
  - **ReasonAff**：重推理的指令（如「找安全的持杯处」），600 对测试图像-任务；
  - **UMD Part Affordance**：17 类物体、7 种可供性，正文记 1,922 张测试图，附录记 2,004 张 ⚠️ 两处不一致；
  - **RAGNet**：3DOI 与 HANDAL 两子集共 3,018 对，仅用于常识库来源/难度的零样本迁移分析。
- **指标**：gIoU（逐样本平均广义交并比）、cIoU（全数据集累计交并比）、P50（交并比过 0.5 的样本比例）、P50-95（0.50 到 0.95 步长 0.05 的平均精度）。
- **默认实现**：决策大脑为 GPT-4o；检测用 Qwen3-VL-235B-A22B（归一化到 0-1000 的框与关键点）；分割用 SAM2-Large；搜索取前 3 条文本与 2 张参考图；交互想象用图像编辑模型生成人在交互的可视化。所有结果为三次随机测试顺序平均（控制情节库的顺序依赖更新）。
- **默认超参**：预算 $B=3$，提交阈值 $\delta=0.8$，一致性下限 $\underline{\omega}=0.5$。
- 诊断权重 $\alpha,\beta,\gamma$ 依次取 0.5、0.3、0.2；检索条数 $N=2$；常识库 200 类、每类 5 样本、容量 1000；情节库容量 80。

## 方法主线

![[images/page_006_fig_fig_3_review.png]]
*图 3：A-Harness 框架总览。证据库累积异构技能输出，两层记忆提供检索先验，路由器按预算选技能，验证器三诊断决定接受或重试，接受后写回情节库。*

### 机制流程

1. **检索与状态组装**：输入图像-指令对 → 用 DINOv3 与 SigLIP 特征拼接做检索嵌入，从两层记忆取前 2 条先验 → 组装出包含观测、指令、当前证据库、记忆先验与剩余预算的状态，交给路由器。
2. **路由与执行**：路由器按「估计验证分增益 / 估计成本」比选下一个动作（选哪个技能、带什么参数）；技能执行后，解析函数把输出包成带溯源的七元组证据并入证据库——生产者编号支撑跨技能对账与冲突时的定点重跑。七元组形如：

$$\xi=\langle\tau,\;p,\;r,\;\lambda,\;\iota,\;c,\;t\rangle$$

3. **验证门控**：验证器把三诊断量加权合成提交分（权重依次 0.5、0.3、0.2，充分性先过挤压函数）；提交需同时满足「提交分过全局阈值」与「一致性过硬下限」，否则按最大缺口定向重试——一致性缺口精化感兴趣区并重分割，稳定性缺口放大重检，充分性缺口调用互补技能：

$$v_t=\alpha\,\omega_t+\beta\,\zeta_t+\gamma\,\sigma(\mu_t),\qquad \text{commit}\iff v_t\ge\delta\ \wedge\ \omega_t\ge\underline{\omega}$$

4. **最终融合与回写**：预算耗尽或验证通过后，融合策略 $\Phi$ 把累积证据、轨迹与记忆先验组装成视觉-语义上下文，先由检测定位可操作区关键点，再由 SAM2 以该点为提示产出最终掩码；被接受的情节写回测试时库供未来摊销。

### 证据存储与两层记忆

- 证据条目为七元组：类型（框/掩码/文本）、载荷、感兴趣区、尺度、生产者编号、成本、步骤索引；溯源标签让「框-掩码错位」这类冲突能定位到责任技能。
- **常识库**：离线收集频繁物体与部件的原型先验，每条带参考掩码；**测试时情节库**：只收验证器接受的轨迹（动作序列、有效参数范围、证据摘要、结果分）。检索用 DINOv3 与 SigLIP 特征拼接后做余弦相似度。
- **代谢**：两库容量固定；情节库溢出时最旧条目被压缩成「经验胶囊」（摘要 + 稳健参数范围）回存，长期效用保在有界存储内。
- ⚠️ 待核对：回写判据是同一套未校准验证器，错误接受的轨迹会污染记忆；论文只以三次随机顺序平均缓解，无记忆污染率统计。

### 路由器：收益-成本比选择

$$u_t=\arg\max_{u\in\mathcal{U}(z_t)}\frac{\widehat{\Delta v}(u;z_t)}{\widehat{c}(u)}$$

- 增益估计走两段式：验证器缺口启发式优先（一致性缺口建议精化分割、稳定性缺口建议二倍放大重检、充分性缺口建议补未用技能），离题动作打五折折扣；当前两位近平手（差距小于一成）或同一缺口连续两轮未解时，升级到 LLM 决策大脑全量思考，输出带理由的动作。实际约 85% 决策由启发式直采。

### 验证器：三诊断量与提交门控

- 一致性：同一感兴趣区内，检测框填充成掩码后与分割掩码的最大交并比（点输出改用归一化点距）：

$$\omega_t=\max_{b\in\mathcal{B}_t,\;m\in\mathcal{K}_t}\mathrm{IoU}\!\left(\chi(b),\,m\right)$$

- 稳定性：跨尺度预测对投影回原图后计算的平均漂移（掩码用交并比距离，点用归一化欧氏距离）：

$$\zeta_t=1-\frac{1}{|\Pi_t|}\sum_{(\xi_i,\xi_j)\in\Pi_t} d\!\left(\varphi(\xi_i),\,\varphi(\xi_j)\right)$$

- 充分性：证据库内所有条目对当前最优掩码的加权支持计数，类型权重按「分割 0.35 > 检测 0.30 > 想象 0.20 ≳ 搜索 0.15」初始化，再乘自置信、跨工具佐证、跨尺度稳定三个可靠性因子并重归一——无佐证或不稳定的噪声证据（如检索文本）被压向零：

$$\mu_t=\sum_{\xi\in E_t} w_{\tau(\xi)}\,\kappa(\xi,h_t)$$

- 提交双条件即上式：全局阈值防「总分虚高」，一致性硬下限防工具根本性分歧时凭总分蒙混过关。

### 最终融合

$\Phi$ 两阶段：先把参考掩码、检索图像、文本线索、跨尺度预测组装成富上下文，让检测技能在可操作区定准一个关键点（提示词特别要求点落在实体表面而非框中心或空洞）；再由 SAM2 以关键点为提示生成最终掩码。

### 消融：各组件到底贡献了什么

| 配置 | gIoU / cIoU（ReasonAff） | gIoU / cIoU（UMD） |
|---|---|---|
| 完整默认配置 | 60.53 / 54.91 | 52.74 / 50.04 |
| 换 Qwen-3.5 检测 | 62.56 / 56.27 | 54.15 / 53.82 |
| 换 SAM-3 分割 | 61.90 / 56.36 | 53.18 / 50.56 |
| 仅 Det&Seg 技能 | 59.68 / 49.29 | 50.82 / 41.92 |
| **去验证器（仅路由）** | **52.28 / 43.15** | 50.87 / 42.00 |
| 去常识库 | 54.43 / 53.38 | 50.31 / 43.12 |
| 去情节库 | 50.85 / 41.89 | 49.50 / 41.04 |
| 去双记忆 | 49.41 / 39.05 | 48.98 / 42.10 |

- **关键反转**：保留自适应路由但去掉验证器后，ReasonAff 掉到 52.28，**低于仅双技能基线的 59.68**——技能越多、无冲突消解时噪声放大越狠。这是「验证门控是编排前提」的最硬证据。
- 情节库单项掉幅最大（自适应迁移到分布外样本），常识库提供互补先验，双记忆同去掉时掉约 11 个点。
- 骨干替换的增益（约 +2）小于验证器/记忆组件的增益——再次支持「编排为主、骨干为辅」。
- 验证器权重消融（表 8）：一致性权重影响最大（去掉后掉约 7.4 个点），稳定性主要贡献定位精度，充分性是防早提交的保险；任一维度独大都变差。

### 记忆来源与样本难度决定迁移方向（RAGNet 零样本）

| 配置 | 3DOI gIoU | 3DOI cIoU | HANDAL-easy gIoU | HANDAL-hard gIoU |
|---|---|---|---|---|
| Affordance-R1 | 39.0 | 33.4 | 43.1 | 40.7 |
| AffordanceVLM | 38.1 | 39.4 | 58.3 | 58.2 |
| 空常识库 | 56.5 | 47.2 | 58.4 | 55.3 |
| 常识库来自 UMD | 57.9 | 50.9 | 62.4 | 49.8 |
| 常识库来自 RAGNet | 63.8 | 52.0 | 61.4 | 60.6 |
| 两源 1:1 混合 | 59.3 | 45.4 | 62.7 | **62.8** |
| 难例库（Claude 大脑） | 62.2 | 52.1 | 60.2 | 59.4 |

- **解读**：空库已能打（56.5 起步）；UMD 源帮 HANDAL-easy 却伤 HANDAL-hard（49.8 低于空库 55.3）——**来源错配会注入检索噪声**；RAGNet 源迁移最均匀。样本难度互补：易例库利于域外迁移，难例库利于域内难例。记忆构建要在来源覆盖与样本难度间平衡。
- ⚠️ 与「语义 > 几何」互证：3DOI 上空库已超专用模型约 18 个点（HANDAL-easy 则与最强专用模型打平），说明编排收益的下限就足够高。

| A-Harness | 60.53 | 5,247 | 5.8 | 2.62 | 52.74 | 5,831 | 6.4 | 2.92 |

- 对全技能固定链：令牌省 45%、延迟省 53%、成本省 45%，精度还涨 5.5 个点；对 A4-Agent 全面占优。
- ⚠️ **但对最小双技能基线，成本反而增加约 37%**（1.92 → 2.62 美元、4.1 → 5.8 秒）。帕累托优势只在「重管线」之间成立；摘要中「降低平均技能调用与延迟」的说法不能外推到轻量管线。
- **重试尾部分布**（表 5，不截断预算）：

| 调用次数 | 样本数（两库） | 平均令牌 | gIoU：ReasonAff | gIoU：UMD |
|---|---|---|---|---|
| 1 | 500 / 1,127 | 4,716 | 0.7437 | 0.6720 |
| 2 | 65 / 365 | 7,309 | 0.5193 | 0.4865 |
| 3 | 21 / 219 | 11,081 | 0.3423 | 0.4213 |
| 4+ | 14 / 293 | ≥15,464 | ≤0.32 | ≤0.31 |

- 多数样本一次检测即解决（ReasonAff 500/600），成本花在难例上；三次调用后收益消失，支撑默认预算取 3。⚠️ 但该表同时显示调用次数与精度强负相关——这是难例子集的自选择效应，不能反证重试无效（见深度分析）。

### 敏感性

- 提交阈值 $\delta$ 从 0.4 提到 0.8 精度单调涨、调用数同步涨；超 0.8 后精度饱和而成本继续涨，默认 0.8 卡在拐点。一致性下限 $\underline{\omega}$ 同型，0.5 后饱和。
- 检索条数 $N$：1 → 2 涨幅最大，3 略升，5 之后检索噪声反噬，默认 2。
- 情节库容量：约 160 后精度饱和、令牌线性涨——语义相近但语境不同的条目会互相干扰。
- 常识库类别覆盖到约 200 类后收益趋平；类内加密采样主要提升 cIoU（稳住大区域而非只会找小接触点）。

## 深度分析

### 为什么有效

- **无门控的技能堆叠是噪声放大器**：搜索文本、想象图这类弱空间证据在晚融合里与强空间证据平权，去验证器变体掉到双技能基线之下就是直接证据。验证器把「要不要采纳」变成逐证据的可靠性调制（类型先验 × 自置信 × 佐证 × 稳定），弱证据只在被强证据佐证时才有发言权。
- **预算花在刀刃上**：85% 路由由启发式直采，LLM 全量思考只留给近平手与顽固定缺口；多数样本单次解决，重试集中在难例——这是令牌减半还能涨点的机制来源。
- **记忆把探索成本摊销**：技能使用随推理进程从早期到后期递减（图 4），情节库积累后相似类别直接走快路；经验胶囊让被淘汰的老经验以压缩形式继续起作用。

### 证据薄弱处与内部不一致（⚠️ 均为本人核查，引用需谨慎）

1. **验证器的实现落差**：论文正文把三诊断量写成几何公式（交并比、投影漂移、加权支持计数），但附录案例图显示实际由 LLM 决策大脑按提示词自评打分：案例 2 与案例 3 中 $\mu_t$ 报出 2.10、1.96，超出正文声称的 [0,1] 范围；案例 1 诊断正文写 $\zeta_t=0.42$、合成式却代入 0.45。**「验证器」更像提示词工程而非独立几何模块**——若换算成精确几何计算还能剩多少增益，论文未测。
2. **重试收益未被干净证明**：表 5 的重试组是「验证器不放行」的自选择难例子集，调用次数与精度的负相关主要反映样本难度而非重试失败；论文没有同一样本「重试前 vs 重试后」的配对对照，定向重试的净收益只能靠去验证器消融间接支撑。
3. **跨表数字不一致**：UMD 测试图数正文 1,922 对附录 2,004；「仅 Det&Seg」基线表 1 与表 2 相差约 8 个点。复现对表时须注明出处。
4. **成本口径含混**：表 6 的美元成本未说明计价单位（每样本或全数据集）；且全部基于闭源 API（GPT-4o、Claude、Gemini、GLM、Qwen 旗舰），本地化部署的成本结构完全不同。
5. **记忆泄漏风险**：常识库由 ReasonAff 与 UMD 训练集构建，RAGNet 仅「部分样本用于域外记忆分析」——与零样本声明之间的隔离程度未交代清楚。

## 局限

- **只做 2D 单图**：输入是图像或视角集合，输出是图像坐标系的像素掩码；3D 点云、部分观测、尺度歧义更强的具身场景均未覆盖，框架「自然扩展到关键点/接触区域」只是声明。
- **闭源 API 依赖**：决策大脑、检测、想象全是托管大模型；复现需要多旗舰模型组合，延迟与成本的绝对值不可迁移。
- **验证器未校准**：三诊断量没有概率语义，提交阈值是数据集级调出来的超参；论文自己强调无标签测试时只能相对验证，也就无法给出风险-覆盖率曲线。
- **记忆的顺序依赖与污染**：情节库只收被接受的轨迹，接受判据未校准；测试顺序影响结果，仅以三次随机平均缓解。
- **成本对轻量管线不占优**：相对最小基线令牌多 37%、延迟多 41%；若任务分布以简单样本为主，固定双技能管线更便宜。
- **作者自陈边界**：端到端模型在分布内更高效，本运行时的价值集中在开放世界尾部；两者是互补而非替代。

## 我的笔记

- **对空白地图的直接冲击（2026-09-10）**：
  ① 本文占掉了「可供性领域的测试时计算分配 + 验证门控」槽位：以后任何「按不确定性决定是否调用更多工具/视角」的方案都必须引用它。**但它不是置信度校准**——三诊断量无概率语义、无风险覆盖率与期望校准误差评测，G5（置信度校准）槽位仍然空着，且本文反而替 G5 铺了动机：验证器分数由 LLM 自评且未校准，正是选择性预测该进场的地方；评测口径可直接借 TNS 的风险覆盖率、AURC 与固定真阴性率下假拒率三件套。
  ② 它是纯 2D RGB、全观测设定；「3D 点云 + 部分观测 + 证据条件化校准」的耦合槽位它碰不到，反而其证据库/溯源/检索基建可以整体平移到 3D 版本作为起点。
  ③ **对效率叙事（红线 3）的反向压力**：本文证明免训练测试时编排能压过专用微调模型（含 Affordance-R1），这会削弱「推理零重模型」的纯效率卖点——辩护重心应移到「校准的拒答能力 + 3D 部分观测」，而非单纯推理开销。
  ④ 其「验证器 LLM 自评」落差（μ 超 1）是可写的批判点：精确几何计算版验证器 + 校准实验本身就是一篇后续工作的空间。
- **可借的工程模式**：七元组证据记录（带生产者编号）、提交双条件（全局阈值 + 硬下限）、经验胶囊代谢、常识库来源 × 难度交叉消融协议（表 3 的 a-g 配置）都可直接搬。
- **引文关系**：A4-Agent（引文 85）是同谱系前置工作；Affordance-R1（引文 67）既是基线又是 ReasonAff 出处；RAGNet（引文 70）兼是基准与 AffordanceVLM 出处。本领域「智能体化」趋势已从 2D（本文、A4-Agent）开始向 3D 蔓延，窗口期有限。
