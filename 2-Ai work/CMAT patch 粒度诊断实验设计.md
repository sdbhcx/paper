# CMAT patch 粒度诊断实验设计

## 目标与核心假设

**假设 H：** `CMAT` 的 patch 级 affinity 对齐存在**粒度上限**，跨部件 patch 污染 + 均值池化稀释 + 随机 mask 欠采样三者叠加，导致**尺度小于或接近单个 patch 的功能部件**语义对齐受损。

**可证伪预测 P：** 令 $\Delta = \text{aIoU}_{\text{w/ CMAT}} - \text{aIoU}_{\text{w/o CMAT}}$，则 $\Delta$ 随部件尺度减小而**单调衰减**，在小部件桶上趋近于 0 甚至为负。

若实测各桶 $\Delta$ 相当，则 H 被否证 —— `CMAT` 的收益是全局表征质量提升，与 patch 粒度正交，应转向其他解释。

## 关键尺度常量

下游固定 $N=2048$ 点、$G=64$ patch、每 patch $S=32$ 点，**一个 patch = 物体表面的 1.5625%**。所有分桶边界都应与这个尺度对齐。

## 实验矩阵总览

| 编号 | 变量 | 是否需要训练 | 成本 | 作用 |
|------|------|--------------|------|------|
| D0.1 | 无（纯统计） | 否 | 极低 | 验证前提：跨部件 patch 是否真的普遍 |
| D0.2 | 无（纯统计） | 否 | 极低 | 验证监督信号：affinity 目标本身是否有判别力 |
| D1 | 无（重评已有 ckpt） | 否 | 低 | **核心判据**：增益是否随尺度衰减 |
| D2 | 2D 聚合口径 / 池化算子 | 小规模预训练 | 中 | 机制分离：成员集合错配、max/mean 不对称 |
| D3 | affinity 是否去 mask | 全量预训练 | 高 | 检验随机子图欠采样 |
| D4 | `num_group` G | 全量预训练 | 最高 | 定位瓶颈是否在 token 数 |
| D5 | 下游上采样结构 | 仅下游 | 中 | 分离 encoder 瓶颈与上采样瓶颈 |
| D6 | 分组策略（语义 vs 几何） | 全量预训练 | 高 | 解决方案实验 |

**执行顺序必须按成本从低到高**。D0 与 D1 不需要任何训练，应在第一天完成；若 D1 已经否证 H，后面全部不必做。

## D0 前置核查（零训练成本）

### D0.1 patch 污染率统计

**目的：** 量化"跨部件 patch"有多普遍。这是 H 的**前提** —— 若污染率极低，整条论证链不成立。

**数据约束：** 已核实 `PIAD` / `PIADv2` 只提供 **affordance 二值掩码**，**没有 part label**。因此按两条路走：

- **路线 A（无需额外数据，先做）：** 以 affordance 前景/背景定义"部件"。对每个 patch $j$ 计算前景点占比 $p_j$，统计 $0.3 \le p_j \le 0.7$ 的**混合 patch 占比**、以及 $p_j$ 的直方图。这些混合 patch 正是均值池化的受害者。
- **路线 B（需确认数据来源）：** 若 `PIAD` 的物体源自 `PartNet`（**待确认**），可引入外部 part label，计算真实的多类纯度：主导部件占比 $\max_c n_{j,c}/32$ 与归一化熵 $H_j$。

**同时统计：** 混合 patch 的空间分布（是否集中在功能边界），以及"被 KNN 重叠覆盖"的点比例（`Group` 用 KNN 而非划分，理论上存在重叠与遗漏，需实测覆盖率）。

**代码位置：** `models/pointmae_official.py` 的 `Group.forward` 返回 `idx`，直接复用即可。

### D0.2 affinity 目标的判别力检验

**目的：** 这是**最容易被忽略但最致命**的一项。余弦相似度矩阵若数值高度集中（DINO 类特征普遍存在"向均值方向坍缩"倾向），则 $L_{aff}$ 主要在拟合一个接近常数的目标，模型只需把所有 patch 特征对齐到同一方向就能大幅降 loss —— 那么 44.13 的提升未必来自"结构迁移"。

**做法（纯统计，Stage 0 产出上直接算）：**

1. 计算全量 $A^{2D}$（非对角元素）的**均值、标准差、分位数直方图**。
2. 用 GT mask 把 patch 分为前景主导（$p>0.7$）、背景主导（$p<0.3$）两类，计算
   $$\Delta_{disc} = \mathbb{E}[A^{2D}_{\text{同组对}}] - \mathbb{E}[A^{2D}_{\text{跨组对}}]$$
3. 把 $A^{2D}$ 的每一行当作该 patch 的"关系签名"，做线性探针预测该 patch 的部件归属，报告准确率与随机基线的差距。

**判读：** 若 $\text{std}(A^{2D}_{\text{off-diag}})$ 很小（例如 < 0.05）或 $\Delta_{disc}$ 接近 0，则 affinity 目标本身判别力弱，$L_{aff}$ 的作用机制需要重新解释。这项结论会直接改变后续所有实验的解读。

## D1 核心判据：按部件尺度分层的 aIoU（零训练成本）

**做法：**

1. 取 `Ours(w/ CMAT)` 与 `Ours(w/o CMAT)` 两个 checkpoint（后者可用 `model.point_encoder.pretrain: false` 复现，或直接用表 1 的 `Ours(w/o CMAT)` 结果）。
2. 对每个测试样本，统计 GT 正样本占比 $r = |M^+| / N$。
3. 分桶（边界与 patch 尺度对齐）：
   - $<1\%$（$<20$ 点）：明显小于一个 patch
   - $1\text{–}5\%$（20–102 点）：1–3 个 patch
   - $5\text{–}20\%$（102–410 点）：3–13 个 patch
   - $>20\%$（$>410$ 点）：13 个 patch 以上
4. 每桶分别报 `aIoU` / `AUC` / `SIM` / `MAE`，并给出 $\Delta$。

**判读：**
- $\Delta$ 单调递减 → 支持 H。
- 各桶 $\Delta$ 相当 → 否证 H，粒度不是瓶颈。
- 小桶 $\Delta < 0$ → `CMAT` 对小部件有**负面作用**，这是最有力的发现。

**必须规避的四个陷阱：**

1. **`aIoU` 对小目标有系统性偏差**（小目标 IoU 方差大、单点误判影响大）。所以**只看 $\Delta$、不看绝对值** —— 两个模型承受相同偏差，做差可抵消大部分。
2. **必须同时报 `AUC`**。AUC 是排序指标、不受阈值影响，对小目标稳健得多。若 `AUC` 与 `aIoU` 趋势一致，结论才站得住。
3. **affordance 类别与部件尺度高度混淆**（`grasp` 常对应把手=小，`sit` 对应座面=大）。若不做控制，D1 可能只是在测"CMAT 对某些 affordance 类别更有效"。**必须在 affordance 类别内部分桶**，或额外报告每个类别的平均 $r$。
4. **报告每桶样本数与 ≥3 seeds 的 mean±std**。小桶样本少，单点结论不可靠。

**补充对照（"尺度匹配"）：** 在同一 affordance 类别内，取大/小实例对比，彻底消除类别混淆。

## D2 机制分离：聚合口径与池化算子（小规模预训练）

**背景：** 代码里 3D 侧是 `FPS + KNN-32` 邻域（重叠），2D 侧是 `argmin(cdist)` 的 Voronoi 硬分配（互斥）；且 3D 用 **max 池化**、2D 目标用 **均值池化**。两侧对"patch $j$ 包含哪些点"的定义不是同一批点。

**做法：** 只改 `Point-MAE/models/Point_MAE.py` 的 `_aggregate_group_features`，3D 侧不动：

| 变体 | 成员集合 | 池化算子 | 分离出的因素 |
|------|----------|----------|--------------|
| A0（现状） | Voronoi | mean | — |
| A1 | KNN 邻域 | mean | 成员集合错配 |
| A2 | Voronoi | max | 池化算子不对称 |
| A3 | KNN 邻域 | max | 两者合计 |
| A4 | Voronoi | attention pooling | 理论上界 |

**判读：** A3 − A0 给出错配的总代价；A1 − A0 与 A2 − A0 分离两个因素各自的贡献。

**降本：** 先用 50 epoch 或 1/4 预训练数据快速筛选，选定后再跑全量 150 epoch。

## D3 affinity 去 mask（全量预训练）

**目的：** 检验"affinity 只在随机 ~26 节点子图上算"是否损害细粒度关系。

**变体：**
- V0（现状）：`gram_pred = _compute_gram(x_vis)`，只在可见 patch 上算。
- V1：在**全量 64 个 patch** 上算（mask 只作用于重建分支）。实现上先跑一次无 mask 前向拿全量 token 算 $L_{aff}$，再跑 mask 前向算 $L_{rec}$。
- V2：`mask_ratio` 降到 0.3（中间态，控制"可见节点数"这一变量）。

**判读：** 若 V1 > V0 且增益集中在 D1 的 $<1\%$ 与 $1\text{–}5\%$ 桶 → 直接证实随机子图欠采样损害细粒度关系。

**必须的配套对照：** V1 的非对角 pair 数从 $26^2$ 增至 $64^2$（约 6 倍）。虽然 `MSELoss` 取均值使 loss 尺度大致可比，但**必须重扫 $\lambda_{aff} \in \{0.05, 0.1, 0.2\}$**，否则结论不可靠。

**附带统计：** 记录两个小部件 patch 同时可见的实际频率（理论值约 16%）。

## D4 `num_group` 扫描（最贵，最后做）

**目的：** 若瓶颈是 patch 粒度，加密 patch 应带来提升。

**两种扫法，含义不同，建议都做：**

- **(a) 固定 $N=2048$，减小 $S$：** $(G, S) = (64,32), (128,16), (256,8), (512,4)$。成本低，但每 patch 点数变少，特征稳定性下降 —— 会引入混杂。
- **(b) 固定 $S=32$，增大 $N$：** $(N, G) = (2048,64), (4096,128), (8192,256), (16384,512)$。更干净，但训练成本上升。注意 lifted 2D 特征需按新 $N$ 重算 —— 重投影本身很便宜（12 视角最近邻插值），DINOv3 前向是按图像算的，不随 $N$ 变。

**判读：**
- $\text{aIoU}(G)$ 单调上升且 $\Delta(G)$ 单调下降 → `CMAT` 的部分收益确实在补偿粗 patch，加密可替代一部分 `CMAT`。
- $\text{aIoU}(G)$ 上升但 $\Delta(G)$ 基本不变 → 粒度与 `CMAT` 正交，两者可叠加。
- $\text{aIoU}(G)$ 在 $G=128$ 后饱和 → 存在其他瓶颈（上采样或数据），转做 D5。

**降本：** 先只跑 $G \in \{64, 256\}$ 两点定趋势，再决定是否加密。

**关键控制：** 扫描时必须锁定 $G_{\text{pretrain}} = G_{\text{finetune}}$。论文当前是预训练 256、下游 64，这本身就是一个未受控变量。

## D5 下游上采样结构（仅改下游）

**目的：** 分离"encoder 的 64 token 瓶颈"与"单步 FP 上采样瓶颈"。

**现状：** encoder 出 64 token → 投影 → **单层** `PointNetFeaturePropagation` 上采样 $64 \rightarrow 2048$ → **6 层 co-attention 在 2048 点级 token 上跑** → 分割头。2048 个点特征只有 64 个自由度（3-NN 距离加权插值）。

**变体：** 固定 encoder 与预训练权重，只改上采样
- U0（现状）：单层 FP，$64 \rightarrow 2048$
- U1：多级 FP，$64 \rightarrow 256 \rightarrow 1024 \rightarrow 2048$
- U2：在 $G=256$ 下做 co-attention，再 FP 到 2048

**判读：** U1 ≈ U0 而 U2 > U0 → 瓶颈在 token 数，支持"encoder 分辨率是硬瓶颈"。U1 > U0 → 上采样本身也是瓶颈之一。

**显存提示：** co-attention 已在 2048 token 上跑（论文报 4–8 GB），U2 的增量主要在 encoder 侧，可控。

## D6 语义感知分组（解决方案实验）

**做法：** 用 lifted 2D `DINOv3` 特征做分组，替代 `FPS + KNN`
- S0：`FPS + KNN`（基线）
- S1：在 lifted 2D 特征空间做 `KMeans`（$K=64$）
- S2：`NCut` / 超分割
- S3：混合 —— 先 2D 特征聚类，再在簇内用 FPS 保证点数均衡

**主要技术风险（必须在 proposal 里写明）：** 语义簇的**大小不均**（可能 5 点 ~ 200 点），而 `PointMAE` 的 `Group` 要求**固定 32 点**。四种应对：
- (i) 改为可变长度，需改 mini-PointNet 或换用长度无关的聚合。
- (ii) 大簇子采样、小簇合并/上采样，回落到 ~32 点。
- (iii) **（改动最小，推荐先试）** 保留 `FPS+KNN` 的几何 patch 用于**重建**，但 2D 聚合与 affinity 在**语义簇**上算 —— 解耦"重建的几何单元"与"语义对齐的部件单元"。代价是 3D token 与 2D 目标的对应关系变复杂。
- (iv) 先用 2D 特征聚类分配 group id，再在簇内 KNN 补齐到 32 点（同簇内借点）。

**次级风险：** 语义分组让 patch 失去几何规整性，重建任务会变难（重建目标本质是几何补全），可能需要下调 $\lambda_{rec}$ 或把重建也改为语义簇内重建。

## 混淆因素控制清单

每次实验**只允许一个变量变化**。需锁定的变量：

`G` / `S` / `mask_ratio` / `λ_aff` / `λ_rec` / 2D 聚合方式 / 池化算子 / 上采样结构 / random seed / 数据集划分 / 预训练 epoch 数

**额外的通用要求：**
- 固定 seed，**≥3 次重复，报告 mean±std**。点云方法方差大，小桶尤其明显。
- 预训练与下游的 $G$ 必须一致（论文当前不一致）。
- 预训练数据规模固定（论文未消融数据量，这是一个未解耦的混杂因素）。

## "小部件"的两种定义必须分开

- **(i) 几何上的小部件**（占点数少，如按钮）→ 对应 D1 的 $r$ 分桶。
- **(ii) 语义上难的小部件**（如把手 vs 杯口几何相似）→ 与尺度无关，是论文自身的 motivation。

两者混淆会让 D1 结论跑偏。务必用"affordance 类别内部分桶 + 尺度匹配对照"把 (ii) 剥离掉。

## 报告模板

建议一张主表，行 = 变体，列如下：

| 变体 | aIoU(<1%) | aIoU(1–5%) | aIoU(5–20%) | aIoU(>20%) | 整体 aIoU | AUC | SIM | MAE | 参数量 | 训练显存 |
|------|-----------|------------|-------------|------------|-----------|-----|-----|-----|--------|----------|

配图建议：$\Delta$ 随尺度桶的折线图（`w/` − `w/o`，分 PIADv2 Seen / Unseen 两条线）。这张图是整个诊断的"门面图"。

## 最小可行路径（时间有限时）

1. **第一天**：D0.1 + D0.2 + D1（全部零训练成本）。
2. 若 D1 支持 H → 做 D2（小规模），定位到具体机制。
3. 若 D2 证实错配有害 → 直接进 D6-(iii)（改动最小的语义分组）。
4. D3 / D4 / D5 作为补充证据，视算力决定。
