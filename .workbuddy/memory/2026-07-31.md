# 2026-07-31

- 基于 GEAL 与 SAGE 笔记设计了分阶段改进路线：V0 基线诊断，V1 连续局部 3D token 并联 PointNet++，V2 中期语言条件 token 交互，V3 粗到细的可变 token 预算，V4 token-level CAM 一致性，V5 affordance-aware VQ，V6 clean/corrupt 鲁棒一致性训练。
- 明确推荐先以 V4 作为主研究方案，V5–V6 作为高风险扩展；每版要求同时检查 Seen、Unseen、corruption、效率和三随机种子稳定性，避免一次堆叠多个模块。
- 澄清 V1 中的 SAGE 风格 tokenizer 默认输出连续局部 token，而不是离散 code ID；VQ 延后到 V5。PointNet++ 与 tokenizer 不能未经对齐直接相加，应先使用相同局部中心/邻域、线性投影到同一通道维度，再采用残差相加、拼接或门控融合，并通过 token-to-point 映射恢复逐点 affordance。
- 下载 PointGS（CVPR 2026, Song et al., 北京交通大学）论文 PDF 到 `1-inbox`，并在 `2-Ai work` 生成完整 Obsidian 深度笔记。该论文用 3D Gaussian Splatting 作为中间表示桥接 2D-3D 域鸿沟，实现无监督室内点云语义分割（ScanNet-v2 +0.9% mIoU, S3DIS +2.8% mIoU）。核心 pipeline：点云→3D-GS 重建→SAM 多视角分割→scale-aware 对比学习蒸馏到高斯基元→密度去噪+两阶段 ICP 对齐→最近邻标签传播。消融显示 3D-GS 无对齐时反而降低性能（13.1%→3.3%），ICP+Affinity Feature 后恢复至 49.2%。对 affordance grounding 的启示：3D-GS 可作为 2D affordance 先验到 3D 的语义桥梁，但 SAM 是 class-agnostic 需替换为功能语义模型。
