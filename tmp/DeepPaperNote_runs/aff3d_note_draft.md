## 原文摘要翻译

三维可供性分割旨在将三维对象分解为承担不同功能角色的部分, 使模型能够推理对象交互而不仅仅是识别对象。
现有方法大多遵循三维语义分割或基于提示的框架, 在几何线索微弱或模糊时表现不佳, 因为稀疏点云提供的功能信息有限。
为克服这一限制, 本文利用大规模二维视觉基础模型中蕴含的丰富语义知识, 通过跨模态对齐机制引导三维表征学习。
具体而言, 论文提出 `Cross-Modal Affinity Transfer` (`CMAT`), 这是一种预训练策略, 迫使三维编码器与由提升后的二维特征所诱导的语义结构对齐。
`CMAT` 由一个核心的 affinity 对齐目标驱动, 并辅以几何重建和特征多样性两个辅助损失, 共同促进结构化且可区分的特征学习。
在经 `CMAT` 预训练的骨干网络之上, 论文采用一个轻量的可供性分割器, 通过高效的交叉注意力接口将文本或视觉提示注入学习到的三维空间, 在保留预训练阶段建立的语义组织的同时, 实现密集且提示感知的功能区域预测。
大量实验表明, 本文方法在准确性和效率上均持续超越以往最先进方法。

## 创新点

1. **从单点特征对齐转向关系结构对齐。** 以往二维到三维知识迁移多关注逐点特征或粗粒度语义一致, 本文显式要求三维 patch 之间的 affinity 矩阵与二维提升特征的 affinity 矩阵一致, 从而把“部分-整体”的功能关系结构迁移到三维空间。
2. **无需额外三维标注的语义预训练。** `CMAT` 利用冻结的 `DINOv3` 在多视角渲染图上提取特征并反投影到点云, 生成密集的逐点语义监督, 避免了收集昂贵的可供性或部件标注。
3. **轻量下游头验证表征质量。** 论文设计 `Lightweight Affordance Segmentor` (`LAS`), 仅通过六层 `co-attention Transformer` 融合几何与提示词元, 证明只要骨干网络的特征空间足够结构化, 就不必须依赖大型多模态语言模型。
4. **在精度与效率上同时取得优势。** 在 `PIADv2` Seen 划分上, 三百兆参数的模型以 `44.88` 的 `aIoU` 超越四十亿参数的 `GREAT` (`38.03`), 同时显存占用从 16–30 GB 降至 4–8 GB。

## 一句话总结

`CMAT` 通过把 `DINOv3` 诱导的二维语义关系结构迁移到三维点云特征空间, 让轻量的 `LAS` 在文本或视觉提示下取得三维可供性分割的 SOTA 精度与效率。

## 研究问题

三维可供性分割的任务是把三维对象划分为具有不同功能意义的区域, 例如椅子的座面、靠背和椅腿, 或杯子的把手与杯身。
传统方法多遵循三维语义分割的范式, 仅依赖几何信息预测部件级标签。
这类方法隐含一个假设: 功能区别可以从形状直接推断。
然而许多可供性并非由局部几何唯一决定: 杯子的可抓握把手在几何上可能与杯口边缘相似, 可支撑的表面往往光滑对称。
当扫描稀疏、存在遮挡或重建噪声时, 纯几何模型容易产生不稳定或粗糙的功能边界。

近期研究引入基于提示的方法, 通过视觉示例或文本指令引导预测。
例如, 文本查询“这个杯子的哪个部位应该被握住?”或展示手持姿势的视觉提示可以突出相关功能区域。
一些工作进一步引入多模态大语言模型 (`MLLM`) 来解释交互线索。
但即使提示处理更灵活, 这些方法的提升往往与其增加的复杂度不成比例。
本文认为深层原因在于: 它们仍然依赖主要作为几何特征提取器训练的三维编码器。
稀疏点云本身包含的功能线索有限, 如果特征空间没有语义感知的结构, 提示就难以可靠地施加语义。
因此, 可供性分割的关键不是设计更复杂的提示, 而是重新思考三维特征如何学习。

既然瓶颈在三维编码器的语义能力, 自然的问题是: 如何向三维特征注入更强的语义结构?
大规模二维视觉基础模型在大量图像数据上无监督训练, 其特征空间天然形成清晰且结构化的语义组织。
如图 1 所示, `DINOv3` 提取的多视角特征已经把把手、座面等功能一致区域聚成不同簇。
这说明二维视觉表征比纯几何三维嵌入更容易编码语义感知的结构。
受此启发, 本文提出把视觉基础模型的语义知识蒸馏到三维域, 通过多视角特征提升生成密集的逐点语义感知引导, 并借助 `CMAT` 让三维编码器真正内化这种知识。

## 数据与任务定义

### 任务定义

给定输入点云

$$P = \{p_i ∈ ℝ^3\}_{i=1}^N$$

目标是生成一个密集的、受提示条件约束的功能区域图 $M$。
该图可表示为:

$$M ∈ ℝ^N$$

提示可以是文本短语, 例如“自行车的哪些部位应该被握住、坐下和踩踏才能正常骑行?”, 也可以是展示交互姿势的图像。
模型需要为每个点输出一个表示该点属于目标功能区域的概率或置信度。

### 数据来源

- **预训练数据:** 论文使用 `Objaverse` 和 `Behavior-1K` 中的超过 10,000 个三维模型, 覆盖家具、厨具、工具等 101 个日常对象类别。
  对每个模型, 渲染 12 个均匀分布视角的 RGB 图像, 分辨率 224×224, 用冻结的 `DINOv3` ViT-Large 提取最终层的密集特征。
  再通过反投影和最近邻插值将逐像素嵌入提升到三维点云, 得到逐点语义描述符。
  该描述符记为 $F^{2D}$。
- **下游评测数据集:**
  - `PIAD`: 5,162 张交互图像与 7,012 个三维对象, 23 个类别。
  - `PIADv2`: `PIAD` 的大规模扩展, 约 15,213 张图像与 38,889 个三维实例, 43 个类别。
  - `LASO`: 19,751 个点-问题对, 覆盖 8,434 个对象形状, 用于评测文本引导的可供性分割与跨几何泛化。

所有实验均严格遵循官方 train/test 划分以及 Seen/Unseen 划分。

### 评测指标

论文使用四个互补指标:

- `aIoU` (average Intersection over Union): 分割重叠。
- `AUC`: 置信度排序能力。
- `SIM` (shape fidelity): 形状保真度, 反映预测区域与真实区域在结构上的相似性。
- `MAE` (Mean Absolute Error): 分数误差, 越低越好。

## 方法主线

### 机制流程

整体框架由三个紧密连接的阶段组成, 从跨模态 grounding 到任务特定适配:

1. **Stage 0: 二维语义知识提取。** 对三维对象进行多视角渲染, 用冻结的 `DINOv3` 提取密集特征并提升回点云, 得到逐点二维语义描述符以及对应的 affinity 矩阵。这一步为后续预训练提供高质量的语义监督信号。
2. **Stage 1: 跨模态 affinity 迁移 (`CMAT`)。**
   将点云划分为 64 个 patch, 通过 `PointMAE`-style Transformer 得到三维 patch 特征。
   构建三维 affinity 矩阵, 并以语义对齐损失最小化其与二维 affinity 的差异。
   同时辅以几何重建损失与特征多样性损失。
   预训练 150 epochs 后得到结构化的三维骨干。
3. **Stage 2: 轻量可供性分割器 (`LAS`)。**
   将 `CMAT` 预训练骨干生成的几何 patch 词元与文本/视觉提示词元投影到共享嵌入空间。
   加入可学习的模态嵌入后拼接, 经六层 `co-attention Transformer` 双向交互。
   再上采样到原始点分辨率, 通过轻量 MLP 头输出最终功能区域掩码。

### Stage 0: 二维语义知识提取

`Objaverse` 和 `Behavior-1K` 提供丰富的语义覆盖。
对每个三维模型, 渲染 12 个视角后, 冻结的 `DINOv3` 输出密集特征图。
这些逐像素嵌入通过已知的相机参数反投影到三维点云, 并对每个三维点聚合多视角信息, 最终形成逐点语义描述符 $F^{2D}$。
提升后的特征不仅包含几何信息, 更蕴含功能语义, 例如“把手”区域在 `DINOv3` 特征空间中倾向于形成独立簇。

### Stage 1: Cross-Modal Affinity Transfer

三维骨干 $Φ^{3D}$ 采用 `PointMAE`-style Transformer, 输入点云被分组为 64 个 patch 词元。
对每个 patch, 将其中包含的点的二维和三维特征分别平均池化, 得到 patch-level 特征。

二维 patch 特征:

$$\bar{f}_j^{2D} = \frac{1}{|P_j|} \sum_{p_i ∈ P_j} f_i^{2D}$$

三维 patch 特征:

$$\bar{f}_j^{3D} = \frac{1}{|P_j|} \sum_{p_i ∈ P_j} f_i^{3D}$$

基于这些 patch 特征构建跨模态 affinity 矩阵:

$$A_{jk}^{2D} = \frac{\bar{f}_j^{2D} · \bar{f}_k^{2D}}{\|\bar{f}_j^{2D}\| \|\bar{f}_k^{2D}\|}$$

$A^{3D}$ 以相同方式由 $\bar{f}^{3D}$ 计算得到。
$m × m$ 的 affinity 矩阵编码了部分之间的语义关系, 二维空间提供结构引导, 三维空间则学习与之对齐。

#### 预训练目标

核心损失是 **语义对齐损失** (`Semantic Alignment Loss`):
该损失直接对齐 $A^{3D}$ 与 $A^{2D}$:

$$L_{aff} = \sum_{j=1}^{m} \sum_{k=1}^{m} \left(A_{jk}^{3D} - A_{jk}^{2D}\right)^2$$

该损失不需要显式语义标签或部件标注, 即可把二维中的功能关系结构注入三维特征空间。

为防止三维编码器遗忘几何信息并避免特征坍塌, 论文加入两个辅助损失:

- **几何重建损失 $L_{rec}$:** 采用 `PointMAE` 的 masked autoencoding 策略, 掩码比率为 60%, 保持骨干网络对点云几何结构的理解。
- **特征多样性损失 $L_{div}$:** 使用 `KoLeo regularizer`, 惩罚嵌入空间中过小的最近邻距离, 最大化特征熵, 使特征更可区分。

总预训练损失为:

$$L_{pretrain} = λ_{aff} L_{aff} + λ_{rec} L_{rec} + λ_{div} L_{div}$$

实现中权重为 $λ_{rec}=1.0$, $λ_{aff}=0.1$, $λ_{div}=0.2$。
预训练 150 epochs, batch size 128, 使用 `AdamW` 优化器, 初始学习率 $10^{-4}$, 余弦衰减, warmup 15 epochs。

### Stage 2: Lightweight Affordance Segmentor

`LAS` 的目标是在保留预训练语义组织的前提下, 以较低的计算开销实现提示感知的密集预测。

- **几何编码:** 输入点云经 `CMAT` 预训练的 $Φ^{3D}$ 得到几何 patch 词元 $F^{3D}$。
- **提示编码:** 文本提示用冻结的 `RoBERTa-base` 编码为 $F_{text}$; 视觉提示用冻结的 `DINOv3` ViT-B 编码为 $F_{img}$。
- **共享嵌入空间:** 三类词元分别经投影后加入可学习模态嵌入, 保留模态来源信息:

$$T^P = \text{Proj}_{3D}(F^{3D}) + E_{point}$$

$$T^{text} = \text{Proj}_{text}(F_{text}) + E_{text}$$

$$T^{img} = \text{Proj}_{img}(F_{img}) + E_{img}$$

将所有可用提示词元聚合为 $T^Q$。
将其与几何词元拼接成序列 $[T^Q; T^P]$。
再输入六层 `co-attentional Transformer blocks`。
自注意力机制实现几何词元与提示词元的双向交互: 几何词元被提示条件化, 提示词元则在三维几何中 grounding。

最后, 融合后的 patch 特征 $F_{fused}^{3D}$ 通过特征传播上采样到原始点分辨率, 再经轻量 MLP 头映射为最终分割 logits $M$。

### 消融实验

![Table 4](images/page_008_fig_table_4_review.png)
*论文原图编号: Table 4。在 `PIADv2` Seen 划分上的消融实验, 分析 Stage 1 损失组件与 Stage 2 骨干选择。*

| 配置 | PIADv2 Seen aIoU (%) ↑ |
|------|--------------------------|
| $L_{rec}$ only | 39.27 |
| $L_{rec} + L_{aff}$ | 44.13 |
| $L_{rec} + L_{aff} + L_{div}$ | 44.88 |
| 将 `DINOv3` 替换为 `DINOv2` | 43.26 |
| Stage 2 使用 `PointNet++` 骨干 | 37.91 |
| Stage 2 使用 `PointMAE` 骨干 | 38.16 |

消融结果有三点启示:

1. **affinity 对齐是主要驱动力。** 仅使用几何重建损失 $L_{rec}$ 时 aIoU 为 `39.27`, 加入 $L_{aff}$ 后跃升至 `44.13`, 说明跨模态 affinity 对齐对功能性区域判别至关重要。
2. **特征多样性有边际增益。** 再加入 $L_{div}$ 后提升到 `44.88`, 鼓励局部特征变化有助于捕捉细粒度的功能区域边界。
3. **教师模型越强, 迁移效果越好。** 将 `DINOv3` 替换为 `DINOv2` 后性能从 `44.88` 降至 `43.26`, 说明更丰富的二维语义能更有效地迁移到三维。
4. **预训练本身改变表征质量。** 即使使用 `PointMAE` 原始预训练权重, 无 `CMAT` 的版本也只有 `38.16`。
而加入 `CMAT` 预训练后达到 `44.88`, 差距超过 6.7 个 aIoU 点。
这表明 `CMAT` 不只是更好的初始化, 而是从根本上改变了三维空间的语义组织。

## 深度分析

### 为什么 CMAT 有效?

`CMAT` 的核心洞察是: 功能区域不仅由局部几何决定, 更由部分之间的关系决定。
例如, “把手”之所以是把手, 不仅因为其形状适合抓握, 还因为它与“杯身”存在特定的空间与功能关系。
`DINOv3` 在二维图像中通过自监督学习已经内化了这种关系结构, 表现为特征空间中功能相似区域的聚类。
`CMAT` 通过 affinity 矩阵对齐, 把这种关系结构显式地迁移到三维空间, 而不是简单地让三维特征与二维特征逐点相似。

消融实验定量支持这一点: 仅重建几何 ($L_{rec}$) 只能达到 `39.27` aIoU, 加入 affinity 对齐后跃升至 `44.13`。
这说明几何连续性不足以支持功能推理, 而跨模态关系对齐才是关键。

### 与相关工作的定位差异

- **传统三维可供性方法** (如 `IAGNet`, `PartAfford`) 依赖完全标注的三维数据集学习几何-功能映射, 在类别外泛化受限。本文不依赖更多三维标注, 而是借助二维视觉基础模型提供语义监督。
- **CLIP/VLM-based 提示方法** (如 `OpenAD`, `OpenKD`) 重点在文本-点云对齐或开放词表可供性 grounding。本文不聚焦于扩展词表, 而是改进三维编码器本身的语义组织结构, 使轻量提示头也能取得好效果。
- **MLLM 方法** (如 `GREAT`) 通过大型多模态语言模型解释交互意图, 在开放场景下更灵活, 但参数量和显存开销巨大。本文走“强预训练 + 轻量头”路线, 在封闭 benchmark 上实现更高的精度-效率权衡, 但复杂语言推理的覆盖可能不如 MLLM。
- **其他二维到三维特征迁移工作** (如 `Locate3D`, `ConceptFusion`, `D3Fields`) 也使用 lifted 二维特征, 但主要对齐单点特征或保证粗粒度语义一致。
  `CMAT` 的差异化在于显式建模并迁移 patch 间的 affinity 关系, 从而得到更结构化的三维表征。

### 哪些地方容易被误读

1. **“CMAT 只需要二维特征, 不需要三维标注”不等于“完全无监督”。** 下游 `PIAD`/`LASO` 仍然需要可供性标注来微调 `LAS`; `CMAT` 节省的是大规模三维预训练阶段的语义标注。
2. **效率对比的适用范围。** 与 `GREAT` 的 4B+/16–30 GB 对比成立的前提是两者在相同 benchmark 上比较可供性分割性能。`GREAT` 可能还承担更广泛的 open-vocabulary 任务, 不能简单推断本文模型在所有场景下都优于 `GREAT`。
3. **多模态提示的潜力未在标准 benchmark 中充分验证。** 论文明确指出现有 benchmark 只支持单模态输入, 因此 `LAS` 的多模态融合能力目前只是架构支持, 实际互补增益尚需未来数据集验证。

## 局限

1. **二维教师模型的质量构成上限。** 消融显示 `DINOv3` 明显优于 `DINOv2`, 说明如果二维视觉基础模型对某功能区域语义模糊, 三维侧也会继承该偏差。论文未系统探索不同二维教师或教师组合的影响。
2. **缺乏真实机器人交互验证。** 所有实验均在静态三维对象 benchmark 上进行, 未在真实抓取、操作或动态交互场景中验证预测区域的物理可用性。
3. **CMAT 与数据量的贡献未完全解耦。** 从零训练的 `PointMAE` (`38.16`) 与 `CMAT` 版本 (`44.88`) 的差距可能同时来自预训练数据 (`Objaverse`+`Behavior-1K`) 和 affinity 目标, 消融未单独控制数据量变量。
4. **单模态 benchmark 限制了 LAS 的多模态能力展示。** 文本与视觉提示同时输入时是否产生互补增益, 现有实验无法回答。
5. **未提供公开代码与预训练权重。** 论文未附代码仓库链接, 复现者需要独立实现 `CMAT` 三阶段流程, 增加了验证门槛。

## 我的笔记

- **可迁移的方法论:** `CMAT` 的跨模态 affinity 对齐思路不仅适用于可供性分割, 也可推广到任何需要从二维图像先验学习三维结构关系的任务, 例如三维部件分割、机器人抓取位姿估计、动态场景的功能区域跟踪。
- **复现关键点:** 需要特别注意 `DINOv3` ViT-L 的最终层特征提取、12 视角渲染、反投影时的多视角一致性、64 个 patch 的划分、以及损失权重 $λ_{rec}=1.0$, $λ_{aff}=0.1$, $λ_{div}=0.2$。任意一项设置偏离都可能导致性能不复现。
- **后续可探索方向:**
  - 将 `CMAT` 与 `SAM` 或 `CLIP` 等具有不同语义粒度的二维教师结合, 观察 affinity 结构变化。
  - 在真实机器人抓取数据上验证 `CMAT` 预训练对抓取成功率的提升。
  - 构建同时支持文本+视觉提示的 affordance benchmark, 真正释放 `LAS` 的多模态设计。
- **与自身研究的关联:** 本工作属于可供性落地（affordance grounding）研究知识库。
  其核心概念包括跨模态亲和度迁移（cross-modal affinity transfer）与提升后的二维特征（lifted 2D features）。
  此外也包括轻量提示融合（lightweight prompt fusion）。
  这些概念可作为后续阅读 `Locate3D`、`ConceptFusion`、`D3Fields`、`GREAT` 时的参照系。
